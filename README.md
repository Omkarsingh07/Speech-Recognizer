# Speech Emotion Recognition

A web application that uses deep learning to detect emotions from speech audio files.

## Features

- Upload audio files (.wav, .mp3) for emotion detection
- Detects 7 emotions: Angry, Disgust, Fear, Happy, Neutral, Sad, and Surprise
- User-friendly interface built with Streamlit

## Technologies Used

- Python
- TensorFlow and Keras for the model
- Streamlit for the web interface
- Librosa for audio processing

## Installation

1. Clone the repository
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the app:
   ```
   streamlit run app.py
   ```

## Usage

1. Navigate to the "Model Tester" page
2. Upload an audio file (.wav or .mp3)
3. The model will analyze the audio and predict the emotion
